## Открытие выбора документов

Для текущего каталога:

```sh
mdv -i
```

Или для указанного каталога:

```sh
mdv docs/
```

Когда ввод и вывод связаны с терминалом, запуск `mdv` без аргументов также открывает текущий каталог. При перенаправленном выводе этот режим автоматически не включается.

Если передать файл или стандартный ввод, `--interactive` сразу откроет документ в выбранном просмотрщике. Вывод интерактивного режима должен быть связан с терминалом:

```sh
mdv -i README.md
cat notes.md | mdv -i -
```

## Поиск документа

Программа рекурсивно находит Markdown-файлы и поддерживает нечёткую фильтрацию. Результаты появляются по мере сканирования, поэтому искать документ можно до завершения обхода.

Выберите документ, чтобы открыть его в постраничном просмотре. Встроенный режим предоставляет поиск, копирование, оглавление и переход к строке исходника.

## Игнорируемые файлы

Поиск учитывает скрытые файлы и правила исключения, включая `.gitignore`.

Нажмите `.`, чтобы переключить показ файлов, исключённых правилами Git. Скрытые пути, правила `.ignore` и `node_modules` продолжают исключаться в обоих режимах.

## Настройка оформления

```sh
mdv --theme nord docs/
mdv --preset reader -i
```

Тема также задаёт палитру интерактивного интерфейса. Подробнее в разделах [Темы](../themes/) и [Просмотр и редактор](../pager/).

## Клавиатура и мышь

| Клавиша | Действие |
| --- | --- |
| `Enter` | Открыть выбранный документ. |
| `j` / `k`, `Down` / `Up` | Следующий/предыдущий результат. |
| `h` / `l`, `Left` / `Right`, `PageUp` / `PageDown` | Страница назад/вперёд. |
| `g` / `Home`, `G` / `End` | Первый/последний результат. |
| `/`, `Ctrl+F` | Редактировать нечёткий фильтр. |
| `Esc` | Отменить или очистить фильтр; сначала закрыть открытую справку. |
| `Tab`, `Shift+Tab`, `H`, `L` | Перейти между разделами результатов. |
| `.` | Переключить файлы, исключённые правилами Git. |
| `e` | Открыть выбранный файл в настроенном редакторе. |
| `r` | Повторно просканировать каталог. |
| `!` | Показать ошибки поиска/открытия. |
| `?` | Переключить справку. |
| `q`, `Ctrl+C` | Выйти. |

Колесо мыши меняет выбранный результат.

- При редактировании фильтра вводите или вставляйте текст, Backspace удаляет символы.
- Enter подтверждает фильтр; повторный Enter открывает выбранный результат.
- Tab, стрелки и Ctrl+J/Ctrl+K также завершают редактирование фильтра.
- Esc отменяет фильтр.
- Явный `--interactive` нельзя сочетать с `--pager`; документы из выбора файлов используют просмотрщик, выбранный через `MDV_PAGER`.

## Встроенный постраничный просмотр

```sh
mdv --pager README.md
```

Параметр `--pager` без значения использует `MDV_PAGER`, если переменная задана, иначе стандартный механизм просмотра. Встроенный режим можно выбрать явно:

```sh
mdv --pager=builtin README.md
```

## Навигация

| Клавиша | Действие |
| --- | --- |
| `?` | Открыть или закрыть справку. |
| `/` или `Ctrl+F` | Искать по документу. |
| `t` | Переключить оглавление. |
| `:` | Перейти к строке исходного Markdown. |
| `l` | Переключить режим нумерации строк. |
| `r` | Обновить текущий файл. |
| `Esc` | Закрыть текущую панель или режим перед выходом. |
| `k` / `Up`, `j` / `Down` | Строка вверх/вниз. |
| `b` / `PageUp`, `f` / `PageDown` | Страница вверх/вниз. |
| `u` / `Ctrl+U`, `d` / `Ctrl+D` | Половина страницы вверх/вниз. |
| `g` / `Home`, `G` / `End` | Начало/конец документа. |
| `h` / `Left`, `Right` | Горизонтальная прокрутка; `l` в mdv переключает номера строк. |
| `n`, `N` / `p` | Следующее/предыдущее совпадение поиска. |
| `q` | Выйти из просмотрщика. |

Панель справки показывает доступное управление для текущего режима.

## Копирование текста

Выделите оформленный текст и нажмите `c`, `Ctrl+C` или правую кнопку мыши. `Ctrl+A` выделяет весь документ, включая содержимое за пределами видимой области.

Скопированный текст не содержит управляющих последовательностей цветов и гиперссылок терминала.

## Открытие редактора

Нажмите `e`, чтобы открыть текущий файл в редакторе. Команда редактора задаётся в `MDV_EDITOR` или `EDITOR`; `MDV_EDITOR` имеет приоритет.

Действия с файлом доступны для документов, открытых из файла. У документа из стандартного ввода нет исходного файла для открытия или обновления.

## Внешний пейджер

```sh
mdv --pager="less -R" README.md
```

Внешний пейджер получает оформленный текст и использует собственное управление. Параметры сохранения цветов, например `less -R`, относятся к команде внешнего пейджера.

## Поведение поиска

Поиск показывает совпадения во время ввода.

- При повторном открытии предыдущий запрос восстанавливается и выделяется.
- Esc закрывает строку поиска, сохраняя запрос и показанную позицию; вне строки поиска Esc сначала очищает выделение совпадений, а последующее нажатие выходит.
- Явная очистка запроса отключает его восстановление.
- Выделяйте текст перетаскиванием левой кнопкой мыши, затем копируйте; без непустого выделения команда копирования не меняет буфер обмена.

## Оглавление

`t` переключает оглавление.

- Единственный заголовок самого высокого уровня пропускается, следующие два различных уровня образуют разделы и подразделы.
- `J`/`K` или Shift+Down/Up переключают разделы.
- Alt+Up/Down выбирает соседние записи.
- Клавиши `1` по `9` выбирают или циклически переключают группы.
- `D`/`U` или Alt+Shift+Down/Up прокручивают оглавление отдельно.
- Клик выбирает запись, колесо над оглавлением прокручивает его.
- При ширине от 72 столбцов оглавление занимает место рядом с документом, иначе отображается поверх него.
- Поиск и переход к строке закрывают оглавление.

## Обновление и позиции исходника

`:` принимает физический номер строки Markdown, начиная с единицы, и выделяет цель.

- Esc возвращает режим нумерации, выбранный через `l`.
- Файловый документ обновляется клавишей `r`; встроенный просмотрщик также отслеживает изменения исходника.
- Обновление сохраняет нумерацию и видимость оглавления, очищая устаревшие выделения и отметки переходов.
- При ошибке текущий документ сохраняется.

## Режимы редактора и выбор просмотрщика

`MDV_EDITOR` важнее `EDITOR`.

- Известные графические редакторы запускаются асинхронно, терминальные ожидают завершения.
- `MDV_EDITOR_MODE=tui` принудительно включает ожидание, `gui` разрешает асинхронный запуск неизвестных команд, но не принимается для известных терминальных редакторов.
- Ошибки кавычек, режима или команды показываются без запуска.
- После возврата из редактора документ может обновиться.
- Подробности приведены в разделе [Переменные окружения](../environment/).

Просмотрщик выбирается по порядку: явный `--pager=COMMAND`, затем `MDV_PAGER`, затем встроенный режим.

- `default` выбирает стандартный backend (сейчас встроенный), `builtin` явно включает встроенный.
- Один `MDV_PAGER` не включает постраничный просмотр обычного вывода.
- Пустые, некорректные и рекурсивные команды mdv приводят к ошибке даже при переопределении окружения через CLI.
- Внешние команды запускаются напрямую без раскрытия оболочкой и требуют собственных аргументов сохранения цветов.
- При перенаправленном stdout просмотрщик отключается.
- `--color never` отключает декоративные цвета и гиперссылки, сохраняя переходы, выделение, копирование и обновление.

## Чтение файла

Передайте Markdown-файл для отображения в терминале:

```sh
mdv README.md
mdv --theme nord --cols 100 README.md
```

Выберите [пресет](../presets/), чтобы применить набор параметров:

```sh
mdv --preset reader README.md
```

## Чтение из потока

В конвейере mdv читает стандартный ввод. Один дефис выбирает его явно:

```sh
cat notes.md | mdv
mdv -
```

## Выбор файла в каталоге

Передайте каталог или включите интерактивный режим для текущего каталога:

```sh
mdv docs/
mdv -i
```

Запуск `mdv` без аргументов в терминале также открывает выбор документов. Правила поиска описаны в разделе [Выбор документов](../browser/).

## Постраничный просмотр

```sh
mdv --pager README.md
```

Встроенный просмотр добавляет поиск, копирование, переход к строке исходника и открытие редактора. Управление описано в разделе [Просмотр и редактор](../pager/).

## Переход к разделу

```sh
mdv --from 'Установка' README-RU.md
mdv --from 'Установка:20' README-RU.md
```

`--from` начинает с первого совпадения текста. Суффикс `:20` ограничивает диапазон исходника 20 строками. `--reverse` начинает с конца, сохраняя оформление блоков.

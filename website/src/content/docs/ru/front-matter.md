## Распознаваемый ввод

Front matter начинается на первой строке с точного `---`, заканчивается точным `---` и содержит mapping свойств YAML. `source` отключает выделение свойств. Разделитель ниже первой строки не начинает front matter.

```markdown
---
title: Example
author: Alice
tags: [guide, terminal]
---

# Document

The body starts here.
```

## Режимы отображения

| `--front-matter` | Результат |
| --- | --- |
| `hidden` | Скрыть свойства, используется по умолчанию. |
| `panel` | Панель свойств через оформление выносок. |
| `table` | Два столбца: свойство и значение. |
| `plain` | Одна нормализованная пара ключ/значение на строку. |
| `inline` | Один переносимый абзац со свойствами. |
| `blocks` | Каждое значение под ключом, как список определений. |
| `code` | Блок YAML с подсветкой синтаксиса. |
| `source` | Обработать весь исходник как обычный Markdown. |

## Конфигурация и оформление

Режим сохраняется в `front_matter`. Поля темы `front_matter.title`, `key`, `value`, `border` задают оформление панели свойств. `--from` выбирает диапазон тела Markdown после выделения front matter; исходные номера строк сохраняются.

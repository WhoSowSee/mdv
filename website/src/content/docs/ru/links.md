## Отображение ссылок

| `--link-style` | Алиас | Результат |
| --- | --- | --- |
| `clickable` | `c` | Кликабельный текст через OSC 8 без видимого URL, режим по умолчанию. |
| `fclickable` | `fc` | Подчёркнутый кликабельный текст через OSC 8. |
| `inline` | `i` | URL рядом с текстом ссылки. |
| `inlinetable` | `it` | Нумерованные ссылки и таблица URL после соответствующего текстового блока или таблицы. |
| `endtable` | `et` | Нумерованные ссылки и таблица URL в конце документа. |
| `hide` | `h` | Текст ссылки без URL. |

Для OSC 8 нужна поддержка гиперссылок терминалом. `--color never` отключает оформление и OSC 8, сохраняя видимый текст и выбранное представление. `--color always` сохраняет оформление при передаче через поток.

## Переполнение URL

`--link-overflow` принимает `wrap` (по умолчанию), `cut` (сократить длинный URL с `...`), `tablecut` (сокращать в обычном тексте и ячейках таблиц), `none` (разрешить переполнение). Меняется только видимый адрес, но не назначение гиперссылки.

## Размещение сносок

`--footnote-style endnotes` собирает определения в конце документа, а `attached` размещает их сразу после ссылающегося блока, включая абзацы, таблицы и пункты списков. Определения следуют порядку первого использования.

```markdown
A statement with a source.[^source]

[^source]: Additional information.
```

## Отсутствующие и пустые определения

`--missing-footnote-style show` показывает записи-заглушки для отсутствующих, некорректных и пустых определений; это режим по умолчанию. `hide` исключает их из блока сносок. Необязательный цвет темы `footnote_separator` управляет разделителями независимо от Markdown-линий.

## Ширина и поля

Явный `--cols` задаёт общую ширину терминального вывода.

- Без него используется определённая ширина терминала, если она не меньше 20 столбцов, затем значение `cols` из конфигурации, затем 80 столбцов.
- Поля и номера строк уменьшают доступное место.
- Их суммарная ширина должна быть меньше общей.

В `--margin` можно указать одну или обе стороны; пропущенная сторона равна нулю. `--tab-length` задаёт число пробелов вместо табуляции, по умолчанию четыре. Поля терминала не применяются при экспорте HTML.

## Перенос строк и переформатирование абзацев

| Значение `--wrap` | Поведение |
| --- | --- |
| `char` | Перенос по границам графем Unicode, используется по умолчанию. |
| `word` | Перенос по словам; слишком длинные слова разбиваются по графемам. |
| `none` | Без мягких переносов. Ограниченные по ширине ячейки таблиц всё ещё могут разбиваться. |

`--reflow` объединяет мягкие переносы исходника внутри абзаца перед переносом по текущей ширине. Жёсткие переносы Markdown сохраняются. Для этой функции перенос строк должен быть включён.

## Заголовки

| Значение `--heading-layout` | Поведение |
| --- | --- |
| `level` | Отступ заголовка зависит от уровня, содержимое сдвигается ещё на столбец. Режим по умолчанию. |
| `center` | Заголовки по центру, содержимое без отступа. |
| `flat` | Заголовки слева, содержимое с отступом в один столбец. |
| `none` | Заголовки и содержимое слева, без отступа. |

`--show-heading-markers` добавляет маркеры `#` по уровню заголовка. В режиме `level` параметр `--smart-indent` сглаживает скачки, например переход от H1 сразу к H4.

## Таблицы

| Значение `--table-wrap` | Поведение |
| --- | --- |
| `fit` | Уместить ячейки в доступную ширину, используется по умолчанию. |
| `wrap` | Разбить широкую таблицу на последовательные блоки столбцов. |
| `none` | Разрешить горизонтальное переполнение без ограничения ширины ячеек. |

Геометрия таблицы не зависит от `--wrap`, который выбирает места разрыва в ячейках. В ограниченных режимах `fit` и `wrap` ячейка при необходимости разбивается по графемам даже с отключённым переносом текста. `--table-borders` включает полную скруглённую сетку. `--table-smart-indent` уменьшает отступ при нехватке ширины.

## Пустые строки между блоками

`--block-spacing` принимает записи `element:top=N,bottom=N`, разделённые `;`. Пропущенные стороны сохраняют текущие значения. Соседние промежутки схлопываются до большего значения, а не складываются.

Доступные элементы: `paragraph`, `h1` по `h6`, `code-block`, `display-math`, `table`, `horizontal-rule`, `unordered-list`, `ordered-list`, `task-list`, `blockquote`, `callout`, `definition-list`, `inline-references`, `end-references`, `attached-footnotes`, `endnotes`.

<div data-mdv-preview="block-spacing"></div>

В YAML используется mapping, например `paragraph: {top: 0, bottom: 1}` внутри `block_spacing`.

## Разделители и скрытое содержимое

`--horizontal-rule-style pretty` добавляет декоративные окончания, а `simple` рисует сплошную линию. Параметр также управляет HTML `<hr>`, когда включено отображение встроенного HTML.

`--hide-comments` скрывает Markdown-комментарии. `--show-empty-elements` сохраняет обычно скрываемые пустые заголовки, списки, цитаты, блоки кода и таблицы. У [front matter](../front-matter/) есть отдельные режимы отображения.

## Нумерация строк документа

`--line-numbers` без значения нумерует строки отображённого текста. `source` использует физические строки Markdown, `separator` добавляет разделитель, `source;separator` сочетает оба режима. Составные значения заключаются в кавычки. Имя файла после флага без режима остаётся позиционным аргументом.

Нумерация внутри [блоков кода](../code-blocks/) настраивается отдельно.

## Отслеживание файла

```sh
mdv --monitor notes.md
```

Редактируйте и сохраняйте `notes.md` в другой панели. mdv обновляет отображение при изменении исходного файла.

## Сохранение оформления

Совмещайте отслеживание с привычными параметрами:

```sh
mdv --monitor --theme catppuccin --cols 100 notes.md
mdv --monitor --preset reader notes.md
```

При повторном отображении сохраняются выбранные тема и разметка.

## Работа с редактором

Разделите терминал на панели, чтобы одновременно видеть редактор и оформленный документ. Открытие исходника из интерактивного режима описано в разделе [Просмотр и редактор](../pager/).

Отслеживание предназначено для файлов. Для Markdown из другой команды используйте [стандартный ввод](../usage/#чтение-из-потока).
